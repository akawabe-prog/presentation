社内資料　プレゼン後の整理

オフロードを試験台に、
コンテンツ制作部隊の基礎を作る

2026年9月15日のプレゼンで社長からいただいた判断と、それに合わせた位置づけの修正。

2026年9月15日作成：川邉

1. 社長の判断

ご意見受け止め
オフロードのマーケットサイズは極端に小さい。コストと人材はあまり割きたくないオフロード単体で売上を目的化しない。ベース費用ゼロ・固定人員なしの前提はそのまま維持する
その意味で、この取り組みはコンテンツ制作部隊の基礎を作るきっかけになるなら「あり」目的の主従を入れ替える。主：制作部隊の基礎を作ること。従：オフロードの成果。オフロードは、小さくて失敗コストが低いからこそ試験台に向く
JEC は MFJ 管轄で厳格、200台前後。JMX はより特化で台数は減る。JNCC が最多大会前プッシュの配信優先を JNCC・WEX → JEC → JMX とした（反映済み）。JMX は販売でなく集客の題材

2. 位置づけの修正

オフロードは目的ではなく試験台。ここで作った仕組みを、moto／cycle／car／tool に転用できる状態にすることが成果です。

市場が小さいことは、試験台としては利点になります。失敗しても損失が小さく、関係者が少ないため意思決定が速く、データが小さいので仕組みの良し悪しが見えやすい。逆に、ここで回らない仕組みは、大きな事業でも回りません。

3. 転用できる「基礎」

オフロードで作るものを、そのまま他事業で使える形にします。実物はすでにある、または最初の1か月で作ります。

基礎オフロードでの実物他事業への転用
データ由来の量産テンプレート都道府県別の店舗ページ47枚、コース・大会・スクールのデータベース（画面案）moto／cycle／car／tool でも「地域×カテゴリ」のページは同じ型で作れる。AIで量産し人が確認する運用も同一
撮影指示書・納品規格画面案の写真枠に付けたラベル（16:9／9:16／21:9／3:4）商品撮影・店舗撮影・イベント撮影の共通規格に
権利処理の書式写真使用許諾、被写体同意、店舗掲載同意（EC二次利用込み）全事業の撮影に共通
都度募集の仕組み遠方取材のカメラマン兼取材者を1件3万円以内で募集する書式と条件地方のイベント・店舗取材に横展開。固定費を持たない取材網
素材管理とクレジット規則撮影者・日付・許諾状態を素材単位で管理し、記事→EC→SNSの再利用を追う全事業の素材倉庫の型
計測の型UTM→注文の紐づけ、集客記事と販売記事を分けたKPI、大会前プッシュの計測「どの記事が売ったか」を他事業でも同じ表で見る
縦型映像の制作フロー60秒の企画表（画面案の9:16枠）、現地取材者の撮影、川邉の編集Shorts／TikTok／Reels の運用を全事業に
インターンの育成手順素材整理、下書き、データ更新、近隣撮影補助の手順書制作部隊の最初の人員供給源

4. 上限を明文化する

  • ベースの費用はゼロ。川邉が他業務の中で毎週◯時間を固定（時間数は社長と合意する）
  • 人員はインターンのみ。正社員の配置・採用はしない
  • 外注は遠方取材のみ、1件3万円以内、都度
  • オフロードの売上目標は置かない。見るのは仕組みが回ったか（第5章）

5. 何を「回った」とみなすか

基礎6か月後の確認
量産テンプレート都道府県47枚・大会カレンダーが検索流入を生んでいる（Search Console）
都度募集第1優先4地域で各1件以上、3万円以内で取材が成立した
権利処理・素材管理取材した素材が記事とEC商品ページの両方で使われた実績がある
計測記事別・プッシュ別にCVが紐づいて見えている
縦型映像60秒の縦型を月◯本、現地取材者の素材で出せた
インターン手順書に沿って、川邉なしで素材整理と下書きができる

この6つが回っていれば、オフロードの売上が小さくても「制作部隊の基礎はできた」と言えます。回っていなければ、オフロードを止めても失うものはほぼありません。
