時間軸 ── 記事から速報へ、そして縦型映像へ

AIの普及で、記事メディアそのものは陳腐化します。記事は流入を取る道具に割り切り、目的地は縦型映像に置きます。

段階何をするか役割体制・注意

第1段・第2段は6か月で立ち上げ、第3段は素材と取材者が揃った段階で本格化します。段階が進んでも、データベースと顧客リストは資産として残ります。

3. どこに置くのか ご指摘 8

独立ドメインは作りません。offroad.customjapan.net に置きます。

本来の最適は customjapan.net/offroad/ です。ただし既存の通販システム上ではデザインの自由度が低く、EICMAで写真・動画を大量に見せる型のコンテンツが作れません。見せ方を取るため、既存の moto／cycle／car／tool と同じサブドメイン方式を採ります。

既存構造との整合△◎　moto／cycle／car／tool と同型×
撤退コスト低低高

SEO資産の分散について

  • 分散はすでに起きている構造です。moto／cycle／car／tool がサブドメインで成果を出していることが、この方式が機能する実証になります
  • ご懸念の本質は「記事の評価が商品ページに届かないこと」です。これは配置ではなくリンク設計で解決します。記事内の商品はすべて customjapan.net の商品ページへ直接リンクし、共通ヘッダー・フッターで相互に結びます
  • Search Console はドメインプロパティで一括計測でき、分散しても数字が見えなくなることはありません
  • 大会・コース・店舗のデータベースは記事より被リンクを集めやすく、その評価が商品ページへ流れます

5. 誰がやるのか ご指摘 4・5

編集責任者は川邉が持ちます。前回単発で終わった原因が「企画・商品接続・ディレクション・展開・数値報告を誰が持つか」だったことを踏まえ、これを一人に集約します。

編集責任者を一人に置くことで足ります。ベースの費用はゼロとし、川邉が他の業務の中で毎週時間を決めて作業します。アシスタントとしてインターンを活用し、外注費は極力ゼロにします。遠方の取材のみ、カメラマン兼取材者を都度募集します（1件3万円以内）。体制の基礎は末尾の補足に記しました。

6. EICMAをどう使うのか ご指摘 1・6

ご指摘どおり、毎週の記事運営とは別枠で扱います。ただし切り離すのではなく、集客記事と販売記事をつなぐ結節点として使います。

  • 会期：2026年11月5〜8日（11月3〜4日はプレス・業界日）。Fiera Milano Rho
  • 現地で写真・動画・一次情報を収集 → AIと川邉で速報化 → offroad.customjapan.net に掲載 → FB・Instagram・PR TIMESへ展開
  • 会場全体ではなく、オフロードだけを歩く切り口にします。全ブースを網羅する既存メディアと役割を分けます
  • 新規取引の可能性があるブランドは、「EICMAで見た → 取扱開始」を一本の記事の流れにし、集客と販売を直接つなぎます
  • 東京・大阪モーターサイクルショー2027（3月20〜22日、26〜28日）も同じ区分で扱います。鈴鹿8耐などロードレースは対象外です

補足. コンテンツ部隊の基礎 取材・撮影の体制

本件に合わせて、大型イベントの取材、ブランドに必要なイメージ撮影、遠方でも現地で安く撮影できる取材者の配置ができる体制の基礎を作ります。固定費ゼロの3層構造です。

層1　編集中枢

川邉＋インターン。川邉は他業務の中で毎週時間を固定し、企画・編集・ディレクション・WEB制作・基本撮影・数値報告・撤退判断を持つ。インターンはアシスタントとして素材整理、下書き、データ更新、近隣の撮影補助。全ての素材はここを通って公開されます。

層2　現地ネットワーク

地域ごとに1名以上の登録制取材者。案件単価で依頼し、固定費を持ちません。候補は、すでにデータベースにある取材候補店37店、スクール講師（優先度A 11件）、コース運営者、大会会場で活動しているフォトグラファー。現地にいて、機材と土地勘を持っている人を使います。

遠方のみ都度募集。1件3万円以内（交通費込み）。固定費は持たない。近隣は川邉とインターンで撮る。

層3　大型イベント派遣

EICMA は社長または川邉が現地（社長がプレスデーに入られた経験が、そのまま一次情報の強みになります）。東京・大阪MCSは自社。全日本MX・JEC・JNCC は層2の現地取材者。
