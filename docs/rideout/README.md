## 要点

- 独立ドメイン・別ブランドの案は取り下げ、`customjapan.net` 内にコンテンツ領域を作る
- 取引先のうちオフロード商材を扱える店は約5店舗 — 商材はあるが届ける経路がない
- 記事を A(集客) / B(販売) / C(蓄積) に分け、種類ごとに別指標で評価
- 初回案件は EICMA 2026（11/5–8）
- 6か月・約450万円。判断基準は「1CVあたりコストが既存Web広告のCPAを下回るか」
