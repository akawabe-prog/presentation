免許があれば、あとは何もいらない。
手ぶらで走れる場所、全国18カ所。

オフロードを始めたい人の最初の壁は「車両がない」「装備がない」「どこへ行けばいいか分からない」の三つ。この18カ所は、そのすべてを現地で解決できる。

全国112カ所のオフロードコースのうち、レンタル車両かスクールのどちらかがある場所は18カ所。両方そろっているのは14カ所しかない。裏を返せば、この18カ所さえ知っていれば、今週末にでもオフロードは始められる。

MOVIE 06:40 ／ 初めての人がレンタル車で1日走る様子（取材後に入る）

なぜ「レンタルがある」が決定的なのか

オフロード車を買う前に、乗ってみる場所がない。これが、この競技の入口を狭くしてきた。レンタルがあるコースは、「買うかどうか」を決める前の一日を提供する。スクールがあれば、その一日に指導がつく。

たとえば埼玉のオフロードヴィレッジで開かれている「モトクロスごっこ」は、免許がなくても参加でき、車両・装備すべて込みで男性14,000円、女性12,000円。月に10回以上開かれている（スクール詳細）。茨城のウイリー松浦のスクールは13,500円で車両も装備も含み、1名から希望日に開催する（詳細）。
