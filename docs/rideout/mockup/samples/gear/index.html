2DAYSエンデューロに出る前に、
カートに入れておく10のもの。

今週末、全日本エンデューロ第3戦「日高2DAYS」。エントリーは8月31日に締め切られている。出る人がいま買うべきなのは、車両でもブーツでもなく、2日間を走り切るための消耗品だ。

エンデューロは1日目に壊したものを、その夜に直して2日目を走る競技。壊れてから会場で探しても間に合わない。ここに挙げるのは、2日間で「必ず使う」か「壊れる可能性が高い」もの。先頭はタイヤとバッテリー。オフロードで最も減るのはタイヤで、大会ごとの路面で替える。

この記事は、エントリー締切のデータを起点に開催2〜3週前にメール／LINEでプッシュ配信する想定。記事を読まなくても商品ページへ直接行ける。
