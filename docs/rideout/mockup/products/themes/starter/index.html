替えどき早見表

見直すタイミング：はじめるとき、大会に出る前、トランポを用意するとき。項目を押すと商品へ移動します。

項目替えどき（目安）こんなサインが出たら
オフロードヘルメットはじめるとき・転倒で強く打ったら帽体の傷・へこみ／内装のへたり
ゴーグルはじめるときストラップの伸び／スポンジのへたり
オフロードブーツはじめるときソールの減り／バックルの破損
プロテクター（胸・ひざ・首）はじめるときストラップの劣化／シェルの割れ
グローブ・ウェアはじめるとき・破れたら手のひらの擦り切れ／ニーパッドの破れ
工具・タイヤ交換大会に出る前・タイヤを自分で替えるときパンクを自分で直せない
