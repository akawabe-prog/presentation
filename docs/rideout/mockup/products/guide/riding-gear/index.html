GUIDE 03 ／ RIDING GEAR

体を守る、走るための装備。

オフロードはヘルメットとブーツ、プロテクターで体を守るのが基本。レンタル車両のあるコースなら、身につけるものをそろえれば走りに行ける。

01ヘルメットあごが張り出したバイザー付きの形。ゴーグルと組み合わせて使う。シールド付きのアドベンチャー型も。02ゴーグル泥と砂、飛び石から目を守る。03ブーツ足首とすねを守る、いちばん大事な装備。04プロテクター胸・ひざ・ひじ・首を転倒から守る。05グローブレバー操作と、転倒時の手の保護。06ウェア動きやすく、擦れに強いジャージとパンツ。
