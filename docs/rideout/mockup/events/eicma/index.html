EICMA 2026

世界のオフロード新型が最初に姿を見せる場所。

イベントは「競技」と分けるショーは大会ではない。オフロードの新型・用品が最初に見える場所として扱い、会場全体ではなくオフロードだけを歩く切り口で記事にする。

RIDEOUT はここで何を見るか

ORIGINAL / VIDEO

オフロードだけを歩く（縦型・60秒×数本）

会場のオフロード車両・用品ブースだけを回る。全ブースを網羅する既存メディアと役割を分ける。取材後に入る。

ORIGINAL / LIST

発表されたオフロード新型の一覧と、国内導入の見込み

車両は競技別（モトクロス／エンデューロ／トライアル）に、用品はブーツ・ゴーグル・プロテクターに分けて。取材後に入る。

COMMERCE

会場で見た用品を、そのまま買える棚

ショーで手に取った新作ブーツ・ゴーグルが、カスタムジャパンで取り扱いがあれば記事から直接カートへ。
